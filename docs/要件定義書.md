# キャラクター体型シミュレーター 要件定義書

版: 1.7（実装に合わせて更新） / 初版作成日: 2026-10-09 / 更新日: 2026-10-10

## 1. 目的・背景
創作でキャラクターを作る際、身長と体重の設定に迷う。数字だけでは体型のイメージが湧かないため、身長・性別・筋肉量・体脂肪率から妥当な体重を算出し、3Dで体型を確認できるWebサイトを作る。
二人のキャラクターを並べて、身長差・体格差・目線の高さの違いを確認できるようにする。

## 2. 対象ユーザー
- 小説・漫画・イラスト・TRPG・ゲームなどでキャラクター設定を作る創作者
- IT の専門知識がない人（スマホでも使える）

## 3. スコープ
### 対象
- 二人分のキャラクター入力、体重・BMI 等の算出、3D 体型表示、二人比較
- パターンの保存・呼び出し、操作の戻る・進む、共有 URL、画像保存

### 対象外
- 年齢による体型変化（成人のみ。年齢入力は設けない）
- 人種の切り替え（日本人＝アジア系の体型に固定）
- 顔つきの調整（一度試したが、効果が控えめなため採用しなかった）
- 衣装・髪の表現、ポーズ・アニメーションの変更、3D モデルの書き出し（glTF 等）
- ユーザー登録・サーバー保存
- 医療・健康診断としての利用

## 4. 機能要件

### 4.1 入力（キャラクター A・B それぞれ）
| 項目 | 内容 |
|---|---|
| キャラクター名 | 名前の部分は、他の入力欄と同じ丸角の枠で囲み、入力できることが分かるようにする。クリックして入力（最大 20 文字）。空にすると「キャラクターA」「キャラクターB」に戻る |
| 性別 | 男性 / 女性。A・B それぞれ自由に選べる（男女・男同士・女同士のどの組み合わせも可） |
| 身長 | 50〜300cm（スライダー＋数値入力）。創作用に、小人・巨人も想定した範囲 |
| 体型プリセット | 男女別に 7 種類（痩せ型 / 標準 / 細マッチョ・引き締まった / アスリート / ゴリマッチョ・筋肉質 / ぽっちゃり / 肥満）。選ぶと筋肉量・体脂肪率を設定 |
| 筋肉量 | 15〜100%（スライダー）。内部では除脂肪量指数（FFMI）に変換 |
| 体脂肪率 | 男性 6〜40%、女性 14〜48%（スライダー） |
| 胸の大きさ | 女性のみ。0〜100%（50% が標準、5% 刻み）。3D の見た目のみに反映し、体重・BMI には影響しない |
| 体重の指定（任意） | 入力すると、その体重になるよう体脂肪率を逆算する（4.2 参照） |
| 保存したパターン | 4.6 参照 |

### 4.2 算出
- 除脂肪量 = (FFMI − 6.1×(1.8−身長m)) × 身長m²
- 筋肉量(%) → FFMI は折れ線で対応づける（男性 0%:16 / 50%:19 / 100%:25、女性 0%:13.5 / 50%:15.8 / 100%:21）
- 体重 = 除脂肪量 ÷ (1 − 体脂肪率)、BMI = 体重 ÷ 身長m²
- BMI の区分は日本肥満学会の基準（低体重 / 普通体重 / 肥満（1〜4度））
- 表示: 体重、BMI と区分、体脂肪率、脂肪量、除脂肪量、標準体重（BMI22）との差、BMI18.5〜25 に相当する体重範囲、体型の文章説明（筋肉段階＋脂肪段階から自動生成）
- 注意書きを、次の場合に表示する
  - 筋肉が多くて BMI が高いが、体脂肪は少ないとき（「肥満ではありません」）
  - 身長が人間の標準的な範囲（130〜220cm）を外れるとき（体重・BMI は拡大・縮小した場合の目安）
  - 体重の指定が作れる範囲を外れるとき
- **体重の指定**:
  1. 筋肉量を固定して、体脂肪率で合わせる。
  2. 体脂肪率の下限（上限）に達したときは、足りない分を筋肉量で合わせ、筋肉量のスライダーにも反映する（整数にそろえ、端数は体脂肪率で吸収する）。
  3. 筋肉量・体脂肪率の範囲でも作れない体重は、作れる最も近い体重にして、注意書きを出す。
  - 例: 男性 185cm では、約 62.6kg（筋肉量 15%・体脂肪率 6%）〜約 144kg（筋肉量 100%・体脂肪率 40%）が作れる範囲。

### 4.3 3D 表示

#### 人体
- MakeHuman（CC0）の素体メッシュと体型データを変換して使い、よりリアルな人体風の滑らかな形状で表示する（日本人＝アジア系・成人の体型に固定）。
- 筋肉量・体脂肪率（体重軸）・胸の大きさ・性別に応じて、スライダー操作に追従してリアルタイムに変形する。
- 素体の A ポーズを、まっすぐ立つ姿勢に補正する。腕は、肘を伸ばして真下に下ろし、脚はまっすぐ、指は中指と平行にそろえる。体が太い・筋肉質なほど、腕・脚を外側へ少しだけ開いて、体へのめり込みを避ける。
- 身長は、姿勢を補正したあとの頭の先から足の裏までで測り、入力した身長に合わせる。
- キャラクターごとに色を分ける（A: 淡い桃色、B: 淡い黄色（薄くて軽い色。淡い色が陰影でくすまないよう、照明は明るめにする））。

#### カメラ・視点
- **平行投影**のカメラを使い、奥行きによる大きさの違いが出ないようにする（奥に置いた目盛りや、立ち位置のずれた二人でも、身長差を正しく比べられる）。
- 二人を同一シーン・同一縮尺で並べる。
- 視点は「正面」「横」の 2 つ。
  - 正面: 二人を左右に並べる。
  - 横: カメラが横から見るので、二人を奥行き方向に並べ、画面上で左右に並んで見えるようにする（A が左、B が右。向かい合わせ）。
- ドラッグで回転（タッチ可）。回転は水平（0 度）までとし、下からの煽りには回らない。最初の視点も水平とする。
- ホイールで拡大縮小（0.6〜4 倍）。
- 表示位置の移動: 右ドラッグ、Shift+ドラッグ。動かせる範囲は制限する。
- スマホ（タッチ）: 1 本指でなぞると回転、2 本指でなぞると表示位置の移動。2 本指でつまむ・広げる（指の間隔が大きく変わったとき）と拡大縮小。移動のつもりで指の間隔が少し変わっただけでは、拡大縮小にならない。ブラウザによるページ全体の拡大・長押しの選択は防ぐ。
- 「表示を戻す」ボタンで、拡大・移動・回転を、その視点の標準の見え方に戻し、動かした人体の立ち位置も初期の位置に戻す（立ち位置の変更は、戻る・進むで元に戻せる）。
- 「正面」「横」を押すと、人体の立ち位置も初期位置に戻る。
- 220cm を超えるキャラクターがいるときは、カメラの範囲・目盛り・立ち位置を自動で拡大して、全身が収まるようにする。

#### 身長の目盛り・文字
- 奥の壁に、10cm ごとの線（50cm ごとに濃い線）と、グリッド床を表示する。
- 目盛りの数字は、画面の左端に固定して表示する。拡大・移動・回転をしても、同じ大きさで、画面の端に出る。拡大するほど刻みを細かく（10cm まで）、離れるほど粗くする。見下ろして数字が重なるときは間引く。

#### 目線
- キャラクターごとに、目の高さを通る、細く薄い青（透明度 50%）の水平線を 1 本引く。線は、二人の目を結ぶ方向に、両方の肩の外側の端までとする（肩より外には出さない）。青い線は、常に人体に重ねて表示する。
- 二人の目の間の顔の表面（顔の外側）どうしを結ぶ、赤い線（青い線より濃い）を引く。赤い線は、一番手前の人体に隠れる。
- 「◯◯ 目線 173cm」の文字を、画面の右端に固定して表示する。二人の目の高さが近いときは、重ならないよう上下に離す。画面が狭いとき（幅 600px 未満、スマホ）は、3D 画面の中には出さず、3D 画面のすぐ上の帯に、A・B の順に表示する（拡大・移動しても、人体と重ならない）。

#### 二人の重なり
- **横から見ているとき**（二人の正面の向きと、カメラの向きが、ほぼ直角のとき。直角から15度以内）は、身長が低い方を前にする。身長も同じなら、体重が軽い方を前にする（体重の差が50g以内なら、普通の奥行き）。
- **それ以外の向き**では、足元（爪先）の位置で決める。カメラから見て、爪先が少しでも手前にある方を、前に描く。爪先がまったく同じ位置（差が1mm以内）なら、身長が低い方を前にする。身長も同じなら、体重が軽い方を前にする。
- 見ている向きに合わせて判定するので、回転すると、前後も入れ替わる。
- 体が重なっていても、色が混ざらず、前の人が全体を見える。

#### 配置図（真上から見た図）
- 水平に見ている画面では、人体を奥・手前に動かしても、見た目の位置が変わらない（平行投影のため）。そこで、二人の立ち位置を真上から見た小さな図を、3D 画面の右下に常に表示する。
- 図には、二人の位置（A・B の色の楕円）、各人の正面の向き（▼）、選択中の人体（枠）、カメラのある向き（● の位置）を出す。上が奥、下が手前（正面から見たとき）。

#### 人体の移動
- 人体をダブルクリック、またはツールバーの「Aを動かす」「Bを動かす」ボタンで選択する（少し明るく光る）。選択中の人体をドラッグすると、左右（画面の横）または前後（画面の縦。上へ動かすと奥、下へ動かすと手前）に平行移動する。動かし始めに左右か前後かを一度だけ決め、斜めには動かない。高さは変わらない。回転して見ているときも、見えている向きに合わせて動く。タッチでは、ボタンで選んだあと、1 本指で画面のどこをなぞっても動く（2 本指は表示位置の移動）。
- 解除は、選択中のボタンをもう一度押す、選択中の人体をダブルクリックする、Esc キー。空きの場所のダブルクリックでは解除しない（スマホで意図せず解除されないため）。ボタンは、短い間の二重の押下を無視する。
- 重なっているときは、手前に見えている方が選ばれる。

### 4.4 二人の比較
- 身長差（cm）、体重差（kg）、BMI 差のサマリーを、キャラクター名で表示する（例:「エルン（男性）はミカ（女性）より、身長は 35cm 高く、体重は 44.0kg 重い（BMI 差 +6.2）」）。

### 4.5 保存・共有
- 入力内容は、ブラウザ（localStorage）に自動保存し、再訪時に復元する（使えない環境でも動作に支障なし）。
- 設定を URL に含める。アドレスバーの URL が、常に共有用 URL になる。「共有 URL をコピー」ボタンもある。
- 「画像を保存」で、3D 表示を PNG として保存する。下部に、キャラクター A の情報を上段、B の情報を下段に表示する（名前・性別・身長・体重・BMI・体脂肪率・目線の高さ）。目盛りと目線の文字も画像に入る。

### 4.6 パターンの保存と呼び出し
- 各キャラクターのパネルで、パターン名を付けて「保存」を押すと、現在の値を保存する。名前を空にすると「パターン N」になる。
- 保存する内容: キャラクター名、性別、身長、筋肉量、体脂肪率、胸の大きさ。
- 保存したパターンは、ボタンとして並ぶ。押すと、そのパネルのキャラクター（A でも B でも）に呼び出し、保存したときのキャラクター名にも変わる。名前を保存していない古いパターンは、名前を変えない。
- 「×」で削除。最大 30 個。ブラウザに保存する（閲覧データを消すと消える）。

### 4.7 戻る・進む
- 「戻る」「進む」ボタン（Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z。文字や数値の入力中は、ブラウザ標準の取り消し）。
- 記録する内容: 名前・性別・身長・筋肉量・体脂肪率・胸の大きさ・体重の指定、人体の立ち位置、「正面/横」の並べ方。視点の回転・拡大・移動は記録しない。
- スライダーを動かし続けている間は 1 工程にまとめ、止めてから約 0.5 秒後に記録する。
- 最大 100 工程まで戻せる。戻した状態から新しい操作をすると、進む側の履歴は消える。

### 4.8 注意書き
- 「創作の参考値であり医学的な診断ではない」「二次元作品では現実より軽く設定される傾向がある」旨を、画面下部に表示する。
- 3D 人体の出典（MakeHuman、CC0）を表示する。

## 5. 非機能要件
- 動作環境: 最新の Chrome / Edge / Safari / Firefox、PC・スマホ（幅 375px 以上）
- 費用・運用: 静的ファイルのみ。サーバー・DB・会員登録不要。
- 性能: スライダー操作に、3D がリアルタイムに追従する。
- 外部通信: 入力データを外部に送信しない。ライブラリ（Three.js）と 3D データは同梱し、オフラインでも動作する。
- 更新の反映: 3D データは、読み込みのたびに更新の有無を確認する。画面のファイル（`app.js` など）には版（`?v=`）を付け、更新のたびに版を変えて、ブラウザが古い版を使い続けないようにする。
- UI: 日本語。ライト/ダーク対応。PC は「A 入力 / 3D / B 入力」の 3 列、スマホは 3D を先頭にした縦積み。
- 保守性: 計算（`body.js`）・3D 人体（`figure.js`）・画面と 3D の制御（`app.js`）を別ファイルに分離。3D データは `tools/convert_makehuman.py` で再生成できる。

## 6. 技術方針
- HTML / CSS / JavaScript（ES Modules）。ビルド不要。
- 3D は Three.js（同梱）。MakeHuman（CC0）の素体メッシュと体型データ（性別 × 筋肉 × 体重、胸の大きさ）を、変形データ（モーフターゲット）として変換し、スライダーに応じて足し合わせる。関節の位置と重みのデータも変換し、姿勢の補正に使う。
- 3D データは、男女で約 2MB ずつ、ほか約 0.2MB。
- ローカル確認は簡易サーバー（`python -m http.server`）。

## 7. 受け入れ基準
- 男性 170cm・標準で約 65kg（64.8kg）、女性 160cm・標準で約 51kg（51.1kg）になる。
- 全スライダーの極端値で、3D モデルが破綻（めり込み・極端な細さ）しない。
- 二人の身長差が、3D 上の目盛りと数値で一致する。
- 身長 50〜300cm の二人を並べても、全身が収まる。
- 体重の指定で、体脂肪率（必要なら筋肉量）が逆算され、作れない体重では注意書きが出る。
- パターンを保存・呼び出し・削除でき、ページを開き直しても残る。
- 戻る・進むで、名前・数値・立ち位置が戻る。
- スマホ幅で横スクロールが発生しない。
