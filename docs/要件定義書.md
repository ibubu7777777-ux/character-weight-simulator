# キャラクター体型シミュレーター 要件定義書

版: 0.3 / 作成日: 2026-10-09

## 1. 目的・背景
創作でキャラクターを作る際、身長と体重の設定に迷う。数字だけでは体型のイメージが湧かないため、身長・性別・筋肉量・体脂肪率から妥当な体重を算出し、3Dで体型を確認できるWebサイトを作る。さらに、二人のキャラクターを並べて身長差・体格差を確認できるようにする。

## 2. 対象ユーザー
- 小説・漫画・イラスト・TRPG・ゲームなどでキャラクター設定を作る創作者
- IT の専門知識がない人（スマホでも使える）

## 3. スコープ
### 対象
- 二人分のキャラクター入力、体重・BMI 等の算出、3D 体型表示、二人比較、画像保存、共有 URL
### 対象外（初期版）
- 年齢による体型変化（成人のみを対象とし、年齢入力は設けない）、人種の切り替え（日本人＝アジア系の体型に固定）、ユーザー登録・サーバー保存、3D モデルの書き出し（glTF 等）、衣装・顔・髪の表現、アニメーション・ポーズ変更、医療・健康診断としての利用

## 4. 機能要件
### 4.1 入力（キャラクター A・B それぞれ）
| 項目 | 内容 |
|---|---|
| 性別 | 男性 / 女性。キャラクターごとに自由に選べる（男女・男同士・女同士のどの組み合わせも可） |
| 身長 | 130〜220cm（スライダー＋数値入力） |
| 筋肉量 | 0〜100%（スライダー）。内部では除脂肪量指数（FFMI）に変換 |
| 体脂肪率 | 性別ごとの範囲（男 6〜40%、女 14〜48%）のスライダー |
| 体型プリセット | 痩せ型 / 標準 / 細マッチョ / アスリート / ゴリマッチョ / ぽっちゃり / 肥満。選ぶと筋肉量・体脂肪率を設定 |
| 体重指定（任意） | 入力すると筋肉量を固定して体脂肪率を逆算。範囲外は丸めて警告表示 |

### 4.2 算出
- 除脂肪量 = (FFMI − 6.1×(1.8−身長m)) × 身長m²
- 体重 = 除脂肪量 ÷ (1 − 体脂肪率)
- BMI = 体重 ÷ 身長m²、区分（低体重 / 普通 / 肥満）
- 表示: 体重、BMI、体脂肪率、脂肪量、除脂肪量、標準体重（BMI22）との差、BMI18.5〜25 に相当する体重範囲
- 体型の文章説明（筋肉段階と脂肪段階から自動生成）

### 4.3 3D 表示
- よりリアルな人体風の滑らかな形状で表示する
- 二人を同一シーン・同一縮尺で並べて表示する（身長差・体格差が実寸比で分かる）
- スライダー操作に追従してリアルタイムに更新（目安: 60fps、最低 30fps）
- 反映内容: 身長＝全体の高さ、筋肉量＝肩幅・胸厚・腕脚の太さ、体脂肪率＝腹・腰・太もも・顔まわり、性別＝基本プロポーション
- ドラッグ（タッチ可）で回転、ホイール/ピンチでズーム、視点プリセット（正面 / 横 / 斜め）
- 身長目盛り（10cm 刻み）とグリッド床を表示
- キャラクターごとに色を分ける（A・B）

### 4.4 二人の比較
- 身長差（cm）、体重差（kg）、BMI 差のサマリー表示（例:「A は B より 12cm 高く、8kg 重い」）

### 4.5 保存・共有
- 入力内容をブラウザ（localStorage）に自動保存し、再訪時に復元（使えない環境でも動作に支障なし）
- 設定を URL にエンコードして共有できる
- 3D 表示と比較結果を PNG 画像として保存できる

### 4.6 注意書き
- 「創作の参考値であり医学的な診断ではない」「二次元作品では現実より軽く設定される傾向がある」旨を表示

## 5. 非機能要件
- 動作環境: 最新の Chrome / Edge / Safari / Firefox、PC・スマホ（幅 375px 以上）
- 費用・運用: 静的ファイルのみ。サーバー・DB・会員登録不要。GitHub Pages 等の無料ホスティングで公開
- 性能: 初回表示 3 秒以内（回線次第）、スライダー操作が引っかからない
- 外部通信: 入力データを外部に送信しない。ライブラリは同梱しオフラインでも動作
- UI: 日本語。ライト/ダーク対応。スマホは縦積み、PC は「A 入力 / 3D / B 入力」の 3 列
- 保守性: 計算ロジック・3D 生成・UI を別ファイルに分離

## 6. 技術方針
- HTML / CSS / JavaScript（ES Modules）。ビルド不要
- 3D は Three.js。パラメトリックな人体メッシュ（ブレンドシェイプ/モーフターゲット方式）で体型を連続変化させる
- 人体モデルは MakeHuman の素体メッシュと体型ターゲット（CC0）を使用。`tools/convert_makehuman.py` で Web 用に変換し、アジア系・成人の形状に固定する（データ量は約 4MB）
- ローカル確認は簡易サーバー（`python -m http.server`）

## 7. 受け入れ基準
- 男性 170cm・標準体型で約 60〜65kg、女性 160cm・標準体型で約 50kg 前後が出る
- 全スライダーの極端値で 3D モデルが破綻（めり込み・極端な細さ）しない
- 二人の身長差が 3D 上の目盛りと数値で一致する
- スマホ幅で横スクロールが発生せず、タッチで回転できる
- 体重指定で体脂肪率が逆算され、範囲外では警告が出る
- 共有 URL を開くと同じ設定が復元され、PNG 保存ができる
